# CatHelp
Images from Pinterest
Somos as Sopa de esferovite. Um grupo de alunas do primeiro ano de design e multimédia

Problema: O problema que decidimos abordar foi a abordagem excecivamente séria para com a saúde mental.

Solução: Criamos um mockup de um site que usaria tanto uma aproach séria como o humor para abordar o assunto. Com um repositório de memes e conteúdo engraçado para destrair dos maus pensamentos, como um sistema de match com terapeutas, através de localização, faixa económica, preferências de abordagem etc., e um sistema de ajuda 24/7 onde terapeutas voluntários estariam sempre disponíveis para atender pessoas em caso de urgência e ou em caso de não terem recursos.

Tecnologias Utilizadas: Figma.

Membros da equipa: Joana Lima, Inês Rocheteau, Sara Cunha
